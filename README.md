# Grupo_1_Herramientas

Este es el repositorio del grupo 1 del proyecto grupal del curso de herramientas de ciencias de datos, el cual se basa en hacer una predicción de la cantidad de turistas que ingresaran al país para el próximo periodo de temporada.
